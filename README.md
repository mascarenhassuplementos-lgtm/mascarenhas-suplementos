# Mascarenhas Suplementos

Loja online de suplementos em Salvador – BA.

- `site/` – o site da loja (publicado pelo GitHub Pages)
- `site/produtos.json` – preços e prazos dos produtos
- `tools/` – programas: atualizador de preços (API do Mercado Livre), catálogo, tabela, ficha e logo
- `.github/workflows/atualizar-precos.yml` – atualiza preços e publica o site a cada 6 horas
- `catalogo/`, `entregas/`, `logo/` – materiais da loja

Configuração passo a passo: veja `GUIA-ATUALIZACAO.md`.
